# PDP Academy — filial loyihalari

Asosiy ish: `xadra-filiali/` — Xadra filiali (1, 2, 3-qavat): rejalar, ish chizmalari, HVAC, past tokli va elektr tizimlari,
3D (Blender), xarajatlar (Excel), albom. **Ishni boshlashdan oldin `xadra-filiali/DAVOM.md` ni o'qing** — joriy holat,
buyurtmachi qarorlari, ochiq savollar va qayta yig'ish tartibi shu yerda. Batafsil fayllar ro'yxati — `xadra-filiali/README.md`.

## Ish qoidalari (buyurtmachi bilan kelishilgan)

- Javoblar — o'zbek tilida, qisqa va aniq.
- O'zingcha ish boshlama va so'ralmagan narsalarga tegma. Buyurtmachi «o'qib ol» desa — faqat o'qib, eslab qol;
  «boshla» deganda bajariladi. Aniqlovchi savollarni ish oxirida ber (bloklovchi bo'lsa — darhol).
- Har o'zgarishdan keyin: `node build.mjs` (kerak bo'lsa `python3 xarajatlar.py` + qayta hisoblash, `node albom.mjs`),
  tekshiruv xatosiz, keyin commit va push. Tayyor fayllarni (PDF/PNG/XLSX) yuklab olish uchun yuborish.
- PR faqat so'ralganda ochiladi.
- Narx Excel'da bo'lsa — o'sha olinadi; bo'lmasa Toshkent bozori bo'yicha taxminiy («TAXMIN» deb belgilanadi).
- Tarixda (eski commitlarda) GitHub token bo'lgan — uni hech qachon qayta chiqarmang, faylga yozmang.
